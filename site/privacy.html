privacy

What notes knows about you

Last updated 24 October 2026

the short version

notes has no account, no server and no analytics. What you put in it stays on your phone, unless you export it yourself.

What it stores

Your goals, habits and ticks, mood, tasks, notes, focus sessions and settings. They live in one database inside the app's own storage on your phone. Nobody else can see them, me included.

What leaves your phone

Nothing, on its own. There is no server for it to talk to, and it sends no analytics or crash reports. A backup only leaves your phone when you export one and pick where it goes: a chat, your drive, a cable to your laptop.

Permissions it asks for

NotificationsFor reminders and the running focus timer. Asked the first time you turn a reminder on, not before.
Alarms & remindersSo a reminder arrives on the exact minute, even with the app closed.
FilesNone. Importing a backup uses Android's file picker, so the app only sees the one file you choose.
InternetAndroid lists it for the app, but notes never uses it. The app's own code makes no network requests.

Deleting it

Settings, then Data, then Erase everything wipes it all on the spot. Uninstalling the app deletes it too. Export a backup first if you want to keep anything.

This website

No cookies, no trackers, no analytics. Downloading the app is a plain file download.

Changes and questions

If any of this changes, the date at the top changes with it. Questions are welcome as an issue on GitHub.

I made notes for myself, then shared it with friends. Kai, 2026.
